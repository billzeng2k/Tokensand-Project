Metric definitions

What counts as completion?

Completed recommendations plus intentional no-action decisions, divided by all terminal runs. Failed, blocked and interrupted runs remain in the denominator. Queued/running runs do not.

What do latency and cost mean?

Latency covers execution through saving a review task, excluding queue wait and analytics delivery. Model latency measures the whole API request. Individual hosted web actions have no measured duration. Cost is an estimate only when all pricing inputs are configured; missing prices show unknown. Demo runs cost $0 and use zero model tokens.

What is retained?

User/assistant messages, prompt version, provided context, sources, public tool results, errors, flag assignment and usage. Hidden model reasoning and credentials are excluded. Full transcripts stay local; only allowlisted metrics go to Amplitude. The operator can inspect individual accounts. Keep this admin listener private.
